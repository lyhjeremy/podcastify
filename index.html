A free, open-source Python tool

Podcastify

Turns an e-book or article into a two-host podcast. One host narrates, a co-host chimes in, and free neural voices render it to a single MP3 with a transcript.

Why two hosts

An audiobook is one voice reading at you. A second voice every few paragraphs is easier to stay with on a walk or a commute. Podcastify takes text you already have and stages it for two voices.

Two modes

rule
The default, with no API key. The narrator reads the source in three-sentence segments and the co-host interjects after every second one. Faithful to the text; the co-host's lines come from a fixed pool, so the result is a two-voice reading.
llm
Set ANTHROPIC_API_KEY and Claude rewrites the source as a host and co-host conversation, told to stay faithful and not invent facts. Costs API usage per run.

Run it

pip install edge-tts ebooklib beautifulsoup4
python podcastify.py book.epub                 # book.podcast.mp3 + transcript
python podcastify.py article.txt --script-only # transcript only
python podcastify.py book.epub --mode llm      # Claude rewrite

ffmpeg is recommended for joining the segments. Voices default to en-US-AndrewNeural and en-US-AvaNeural; --voice-a and --voice-b take any edge-tts voice.

Bring your own text. Podcastify ships no books or audio. Use files you own or public-domain titles, for personal listening. The text of each turn is sent to Microsoft's edge-tts service to be voiced, and in llm mode the source goes to Anthropic's API.
