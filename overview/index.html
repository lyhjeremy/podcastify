Podcastify
any text, staged for two voices

A Python command-line tool

Turn an EPUB or article into a two-host podcast with one command.

Podcastify splits the text into short segments for a narrator, has a co-host interject between them, renders every turn with free Microsoft edge-tts neural voices, and stitches one MP3 with a Markdown transcript. The default mode needs no API key. An optional mode sends the text to Claude, which rewrites it as a back-and-forth between the two hosts.

Captured 2026-10-26 with edge-tts 7.3.1 and ffmpeg. The default voices are en-US-AndrewNeural for the narrator and en-US-AvaNeural for the co-host; --voice-a and --voice-b take any edge-tts voice. The --script-only flag writes the transcript and stops, so you can read a whole book's script before rendering hours of audio.

How it works

Three files, one job each

podcastify.py
The CLI. Reads .epub (ebooklib and BeautifulSoup), .txt, .md or .html, builds the script, writes the transcript, calls the TTS engine
script_builder.py
Splits the text into sentences with a regex, groups them three to a segment, and inserts a co-host reaction and a narrator bridge after every second segment. In llm mode it calls the Anthropic Messages API and asks for the conversation as a JSON array of turns
tts_engine.py
Renders each turn to MP3 with edge-tts, then joins them with ffmpeg's concat demuxer without re-encoding, or byte-joins the MP3s if ffmpeg is missing

Limitations

In rule mode the co-host has nothing to say

Rule mode is faithful to the source and costs nothing, and the price is a co-host who responds to nothing in particular. Its lines come from a pool of twelve reactions and five narrator bridges, so over a long book they repeat, and they can land oddly: "Let me make sure I'm following" after Alice falls down a well. What rule mode produces is a two-voice reading. A second voice every few paragraphs changes the texture of a long listen, but nobody would mistake it for a conversation.

The sentence splitter is a regular expression, and quoted speech trips it. In the sample, the Rabbit's "Oh dear! Oh dear! I shall be late!" is cut across two turns, and the second narration turn runs 51 seconds.

--mode llm is the fix for the first problem. With ANTHROPIC_API_KEY set, Claude rewrites up to 12,000 characters of source into a host and co-host discussion, and the prompt tells it not to invent facts. That mode costs API usage per run, and without a key it falls back to rule mode. edge-tts is an unofficial Microsoft endpoint: version 7.2.8 returned HTTP 403 on 2026-10-26 and 7.3.1 worked, so keep it upgraded.
